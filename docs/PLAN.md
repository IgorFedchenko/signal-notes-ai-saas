# Delivery and acceptance

This reference covers a bounded SaaS client workflow: private note → validated
summary/evidence → persisted usage → clearly disclosed test billing.

Required offline evidence includes real two-user Auth/RLS, atomic Free5/Pro100 count
and estimated exposure limits, acknowledged one-attempt fencing, safe timeout/expiry
and replay behavior, additive legacy upgrade and DB-boundary content deletion.
Structured output/evidence validation, immutable model/prompt/pricing metadata and
privacy-safe telemetry must be exercised through the actual application route.

The frozen 12-case synthetic evaluator and negative controls validate the harness
separately from model quality. Desktop/mobile browser flows, clean one-command
bootstrap/shutdown, actual local Phoenix readback, dependency/security/format gates,
concise docs and genuine demo media complete the local reference evidence.

Live model/judge, Stripe-hosted test payment and hosted deployment are removed from
this case's scope. Their optional adapters remain unconnected; no fixture or mock
may be promoted to a live/hosted claim. Public-only security features are outside
local acceptance while this repository stays private for common portfolio review.
See [verification](VERIFICATION.md) and [local testing](TESTING.md) for evidence.
